# Capability Routing

| Need | Primary capability | Canonical destination |
|---|---|---|
| KPI definition | Data Analytics / design-kpis | `05_KPI/` |
| KPI review/root cause | kpi-reporting + metric-diagnostics | `15_Analytics/` |
| Financial statement/variance | Finance + Spreadsheets | `09_Company/` or `15_Analytics/` |
| Business case | product-business-analysis + Finance | `13_Decisions/business/` |
| Market/customer research | Research + synthesize-research | `11_Research/`, `07_Customer/` |
| Competitive intelligence | competitive brief | `08_Competition/` |
| Marketing plan/performance | Marketing skills | `06_Strategy/`, `03_Playbooks/`, `15_Analytics/` |
| Sales pipeline/forecast | Sales skills | `15_Analytics/` or business decision |
| Product behavior | PostHog | `15_Analytics/`, `14_Experiments/` |
| Design/diagram | Figma | Link/evidence in relevant canonical record |
| Formal deliverable | Documents/Spreadsheets/Presentations/PDF | Artifact plus canonical summary |

Read `90_AI/PLUGIN_REGISTRY.md` before using a plugin and the relevant contract in `90_AI/integrations/`.
